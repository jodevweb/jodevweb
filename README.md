#### 🛩️ [Cockpit](https://github.com/jodevweb/cockpit)

Une application native (macOS et Windows) pour lancer, suivre et piloter des agents de code (Claude Code, Codex, Gemini)
sur des git worktrees : ce que fait chaque agent, ce qui attend ta décision, ce qu'il faut relire.
**Tauri 2 · Rust · React · Tailwind**, sous licence MIT, disponible en 10 langues.
